# THOX GitHub Agent Team (страница-мост)

Полная спецификация находится в [английском исходнике](../../thox-agent-team.md).

## Review coverage

Процесс охватывает задачи, комментарии к задачам, pull request, ручную проверку и ежедневную проверку политики.

## Safe merge gates

Слияние допускается только после успешных обязательных проверок, разрешения защиты ветки, снятия статуса draft, сверки head SHA и ручного просмотра чувствительных изменений.

## Branch pruning

Удаляются только слитые ветки функций из этого репозитория, которые не являются основной или защищённой веткой и не используются другими открытыми PR.
