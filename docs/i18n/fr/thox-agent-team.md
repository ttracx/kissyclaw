# THOX GitHub Agent Team (page passerelle)

Consultez la [source anglaise](../../thox-agent-team.md) pour la spécification complète.

## Review coverage

Le flux couvre les issues, commentaires d’issues, pull requests, validations manuelles et contrôles quotidiens de politique.

## Safe merge gates

Fusion uniquement après réussite des contrôles requis, autorisation de la protection de branche, statut non brouillon, vérification du head SHA et revue humaine des changements sensibles.

## Branch pruning

Supprimer uniquement les branches de fonctionnalité fusionnées du même dépôt, non par défaut, non protégées et non référencées par une autre PR ouverte.
